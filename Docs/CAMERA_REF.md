# day113 審査カメラ 参考（Web版アーティファクトの録画 2026-11-17 07:12 より）

座標は「審査中の絵」基準：原点＝絵の中心（床から約1.5m）、+Z＝壁から手前（観る人側）、+X＝絵に向かって右。
画面はスマホ縦。縦FOV 50〜60。カメラは低め（1.1〜1.45m）で、少し見上げる感じ。動きは全部 ease-in-out（SmoothDamp）、止まっている間もごく小さく漂わせる。

|---|---|---|---|---|
| 1 | 0–1.5s | タイトル「審査会」 | (0, -0.2, 3.2) → 絵の中心 | 正面からゆっくり寄る（Z 3.2→2.8） |

## 札ボンの確認点（Web版はこうなっている）
1. 講評の文字が出てから上げる
2. 腕は体の横から真上まで約0.25秒で振り上げる
3. 札は最初25°くらい傾いて出て、0.3秒で真っすぐに戻る（オーバーシュート→小さく揺れて止まる）
4. 札は頭より上で、画面の中に収まり、数字が読める
5. 同時に右下の赤い点数バッジがポップ（0→1.2→1倍）、上のHUDの点数も更新
6. 「ボン」の音（段階5の効果音で入れる）
7. 1.5秒くらい止めてから下ろし、向きを変えて退場
