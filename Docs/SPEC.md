## 遊びの核
- 赤・黄・青・白・黒の5色チューブをタップして1滴ずつ足し（最大12滴、各チューブの「−」で1滴へらす）、お手本を見ながらキャンバスに描く。
- 混色＝顔料RGB（赤.85/.10/.09、黄.96/.80/.08、青.10/.22/.60、白.97/.96/.93、黒.07/.07/.08）の重み付き幾何平均（mixRGB）。
- 作った色ストック（塗った配合を最大6個、新しい順・重複なし、タップで呼び出し）、1筆もどす（最大12段）、あらう（配合を空に）、筆サイズ4段（通常 4/9/17/28、グラデステージ 5/10/20/32。初期は「太」、グラデは「特太」）、ルーペ（タッチ中のみ指の下を拡大、指が左上のときは右上へ）、まっさら（塗り量3000超は2度押し確認）、横ロック（グラデステージのみ）、お手本拡大、💡混ぜ方ヒント（bestRecipe総当り）。
- 「先生に見せる」は塗り量4000未満なら不可（トースト）。

## 採点（HTML版 grade() をC#へそのまま移植）
- 入力：256×256 の色(base)・高さ(h=.3+平均高さ×1.1)・塗った/塗ってない(painted)、筆の統計(paintedPx, blackPx, mudPx, strokes, strokeLenSum, mixCount)。統計の単位はHTML版と同じ「256座標系」に正規化する。
- 色彩（藍原）：16×16マスのLab差 → (raw−.40)/.52、グラデステージは行ごとの段差・ムラ・一致で7:3合成、黒使用ペナルティ最大18（ステージ3は黒OK）。
- 形（方円）：マスの最近傍領域とお手本領域のJaccard（cellVoteステージは行ごとの代表色で判定）→ (平均−.05)/.75。
- 感性（ふわり）：塗った面積（ステージ3は白キャンバス残しも加点）.30、絵肌の凹凸.25、筆の長さ.25、色相数と混色種類.20。
- 総合＝3人の平均の四捨五入。★＝round(総合/20)。総合50点以上で次ステージ解放。
- 講評セリフ：commentColor/Shape/Feel の分岐と文言をそのまま移植（同点帯の言い回しはランダム選択も同じ）。

## 審査 → 展示会 → 閉幕
- 審査：先生が1人ずつ絵の前へ歩く → 講評（文字送り）→ 点数札＋カウントアップ → 3人並んで総合★と評語（85/65/40点境界）。スキップ可。
- 展示会：来場者 round(総合×0.3)+4 人、出現ペース .35+総合/100×1.25。扉→行列（最後尾札）→鑑賞枠5つ→反応（担当観点の点数/100の確率で❤️、残りを🤔/😅に半々）→退場。HUDに来場/❤️/🤔/😅。
- VIP大富豪：総合70以上、開幕9秒後。購入額 50/300/1000/5000万円（80/88/95点境界）。
- 怪盗：総合80以上。停電（暗転＋警報）→ 絵の前で口上 → スタッフ・先生が驚く → 逃走、BGM切替。
- 閉幕パネル：★、総合、来場者評語（30/20/12人境界）、イベント記録、3人の講評、解放のお知らせ/「あと◯点」、ボタン「見なおす／ステージ／もう一枚」。

## 操作方式
- タップ：チューブ（1滴）／「−」／ストック／ボタン類。ドラッグ：キャンバスに描く（単一指。2本目の指は無視）。
- 筆圧：取れる端末のみ反映（iPhoneの指は筆圧なしが普通）。速度は全端末で反映。
- 振動：対応ブラウザのみ（Android Chrome）。iOS Safariは非対応として扱う。
